ISC-WAI Investor App
Video Tutorial Brief

FOR VIDEO EDITOR Document type: User tutorial · Target length: 3–5 minutes · Languages: English + Urdu voiceover
Product: ISC-WAI (Wakalat Invest) · Tagline: Growth · Transparency · Trust · Brand green: #0F7A2C
Audience: New and existing investors / customers · Style: Step-by-step how-to (not marketing hype)

How to use this document: Follow the scene order below. Each scene lists what to show on screen, what the user taps, and suggested English + Urdu voiceover. Prefer real screen recording of the investor mobile app with dummy/demo data.
Critical product rule (must be clear in the video): Investors do not manually buy gold or stocks. They deposit money → admin credits the wallet → capital is auto-allocated across five investment sleeves (Stock, Tech, Debt, Money Market, Gold). Withdrawals come only from the Money Market (withdrawable) sleeve.

1. Video goals

  • Teach a first-time user how to create an account, complete KYC, deposit, track portfolio, and withdraw.
  • Tour every bottom tab: Home, Stocks, Wallet, Profile, Reports.
  • Explain security: fingerprint, MPIN, trusted device OTP.
  • Keep tone calm, clear, and trustworthy — tutorial, not sales pitch.

4. Full user journey (happy path)

  1. Splash → Create account (or Login)
  2. Optional fingerprint setup
  3. Accept legal consent
  4. Home → first-time risk disclaimer → Continue
  5. Complete KYC (CNIC, bank, nominee, documents) → wait for approval
  6. Deposit with payment proof → wait for admin approval
  7. See wallet credited → Portfolio pie (5 sleeves) → Daily Markets / Stocks
  8. Set Withdrawal MPIN → request Withdrawal
  9. Profile: language Urdu/English, notifications, logout
